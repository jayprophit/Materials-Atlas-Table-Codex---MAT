# Selected Lithium Nuclear Relationships

| Reaction               |     Q-value | Role                                        |
| ---------------------- | ----------: | ------------------------------------------- |
| ⁶Li + n → ⁴He + ³H     | +4.7835 MeV | tritium breeding / neutron interaction      |
| ⁷Li + n → ⁴He + ³H + n | −2.4676 MeV | higher-energy tritium-production branch     |
| ⁷Li + p → 2 × ⁴He      |  exothermic | historic accelerated-particle transmutation |

Chemical and nuclear pathways remain separate.
