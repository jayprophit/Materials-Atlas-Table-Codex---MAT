# Lithium Process Matrix

| Process                      | State Change                    | Class                    |
| ---------------------------- | ------------------------------- | ------------------------ |
| melting                      | solid Li → liquid Li            | thermal                  |
| solidification               | liquid Li → solid phase         | thermal/structural       |
| ionization                   | Li → Li⁺                        | electronic               |
| plating                      | Li⁺ + e⁻ → Li                   | electrochemical          |
| stripping                    | Li → Li⁺ + e⁻                   | electrochemical          |
| intercalation                | host + Li⁺ + e⁻ → Li-host       | electrochemical          |
| lithiation                   | host → Li-containing host/alloy | electrochemical/material |
| water reaction               | Li + H₂O → LiOH + H₂            | chemical                 |
| hydride formation            | Li + H₂ → LiH                   | chemical                 |
| nitride formation            | Li + N₂ → Li₃N                  | chemical                 |
| neutron capture on ⁶Li       | ⁶Li + n → ⁴He + ³H              | nuclear                  |
| high-pressure transformation | Li phase A → phase B            | structural               |
| implantation/deposition      | Li species → surface/film       | manufacturing            |
