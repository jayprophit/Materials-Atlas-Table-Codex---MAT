# Lithium Electrochemical Metrics

| Metric                   | Symbol | Applies To                        |
| ------------------------ | ------ | --------------------------------- |
| electrode potential      | E      | defined electrochemical couple    |
| cell voltage             | Vcell  | complete cell                     |
| specific capacity        | Qs     | active material/system            |
| specific energy          | Es     | complete defined system           |
| Li diffusion coefficient | DLi    | specified host/state              |
| ionic conductivity       | σion   | electrolyte/solid ionic conductor |
| Li occupancy             | xLi    | host material                     |
| state of charge          | SOC    | defined cell/electrode            |
| cycle life               | —      | whole cell/system                 |
| interphase thickness     | —      | defined interface                 |
| volume expansion         | ΔV/V   | specified host/material           |
| current density          | j      | electrode/interface               |

None is a universal scalar property of elemental Lithium.
