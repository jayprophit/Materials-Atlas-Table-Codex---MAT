# Key Lithium Relationships

| Relationship     | Mechanism                           |
| ---------------- | ----------------------------------- |
| Li–H             | hydride chemistry                   |
| ⁶Li–H            | tritium-production nuclear pathway  |
| Li–He            | nuclear reaction products           |
| Li–C             | graphite/intercalation systems      |
| Li–Si            | alloying/lithiation                 |
| Li–O             | oxides, ceramics, battery materials |
| Li–N             | nitride / solid-state ionics        |
| Li–Al            | light alloys                        |
| Li–Mg            | light alloys                        |
| Li–Pb            | breeder/liquid-metal systems        |
| Li–Na/K/Rb/Cs/Fr | alkali-metal periodicity            |

A relationship edge must specify its **mechanism**.
