# Oxide Families

| Family              | Idealized Form / Example | Function Classes          |
| ------------------- | ------------------------ | ------------------------- |
| binary oxide        | MO / M₂O₃ / MO₂          | broad                     |
| perovskite          | ABO₃                     | electronic/ionic/magnetic |
| spinel              | AB₂O₄                    | magnetic/electronic       |
| ferrite             | iron-containing oxide    | magnetic                  |
| TCO                 | ITO/FTO/AZO              | transparent + conductive  |
| oxide-ion conductor | stabilized zirconia      | SOFC/SOEC                 |
| cuprate             | YBa₂Cu₃O₇₋ₓ              | superconductivity         |
| battery oxide       | layered oxides           | electrochemical redox     |
