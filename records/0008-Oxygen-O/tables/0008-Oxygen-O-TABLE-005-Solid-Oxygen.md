# Solid Oxygen Phase Architecture

| Phase | Approximate Regime | Character                                |
| ----- | ------------------ | ---------------------------------------- |
| α     | low T, low P       | antiferromagnetic molecular solid        |
| β     | low P              | molecular magnetic phase                 |
| γ     | higher-T solid     | molecular solid                          |
| δ     | ~5.5+ GPa          | antiferromagnetic states                 |
| ε     | ~8+ GPa            | clustered \((O₂)_4\) / O₈                |
| ζ     | ~96+ GPa           | metallic; superconductivity near 100 GPa |
