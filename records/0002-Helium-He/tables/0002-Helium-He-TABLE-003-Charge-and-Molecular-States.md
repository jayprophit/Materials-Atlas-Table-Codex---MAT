# Helium Charge and Molecular States

| State | MAT ID             | Class                    | Notes                            |
| ----- | ------------------ | ------------------------ | -------------------------------- |
| He    | MAT:0002:ATOM:He   | neutral atom             | ordinary bulk gaseous species    |
| He⁺   | MAT:0002:ION:He+1  | atomic ion               | one electron                     |
| He²⁺  | MAT:0002:ION:He+2  | bare nucleus             | ⁴He²⁺ is an alpha particle       |
| ⁴He₂  | MAT:0002:MOL:He2   | weak van-der-Waals dimer | extraordinarily weak bound state |
| He₂⁺  | MAT:0002:ION:He2+1 | molecular ion            | specialized species              |
| He₂*  | MAT:0002:MOL:He2*  | excited dimer / excimer  | specialized excited state        |
| HeH⁺  | MAT:0002:ION:HeH+1 | molecular ion            | detected astrophysically         |

Ordinary bulk helium remains monatomic.
