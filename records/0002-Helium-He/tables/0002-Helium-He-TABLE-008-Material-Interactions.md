# Helium Material Interactions

| Interaction         | Host Context                     | Possible Result                    |
| ------------------- | -------------------------------- | ---------------------------------- |
| implantation        | solids                           | interstitial He                    |
| defect trapping     | irradiated material              | trapped helium                     |
| vacancy association | crystal defects                  | He-vacancy complexes               |
| clustering          | accumulated helium               | helium clusters                    |
| bubble formation    | irradiated / implanted materials | He bubbles                         |
| cryogenic contact   | equipment/materials              | extreme cooling                    |
| leak transport      | seals / systems                  | leak-detection signal              |
| inert atmosphere    | processing environment           | reduced reactive-gas participation |

These are relationship properties, not intrinsic mechanical constants of Helium.
