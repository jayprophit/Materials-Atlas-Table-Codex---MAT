# Helium-4 Reference Points

| Reference            | Temperature |  Pressure | Notes                           | Source     |
| -------------------- | ----------: | --------: | ------------------------------- | ---------- |
| Normal boiling point |    4.2221 K | 101325 Pa | liquid-vapor reference          | SRC-000025 |
| Critical point       |    5.1953 K | 227460 Pa | critical state                  | SRC-000025 |
| Lower lambda point   |    2.1768 K | 5041.8 Pa | He-I / He-II boundary reference | SRC-000025 |

The lambda line is pressure-dependent.

The value `2.1768 K` must not be stored as one universal pressure-independent phase-transition value.
