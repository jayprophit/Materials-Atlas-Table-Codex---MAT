# Boron Allotrope Architecture

| State         | Structural Family | Major Motif               | Electronic/State Note                |
| ------------- | ----------------- | ------------------------- | ------------------------------------ |
| α-B₁₂         | rhombohedral      | B₁₂ icosahedron           | semiconducting                       |
| β-B₁₀₆        | rhombohedral      | complex B₁₂-based network | intrinsic partial occupancy/disorder |
| γ-B₂₈         | orthorhombic Pnnm | B₁₂ + B₂                  | high-pressure phase                  |
| t-B₅₂ family  | tetragonal        | cluster-rich              | complex                              |
| t-B₁₉₂ family | tetragonal        | cluster-rich              | complex                              |
| amorphous B   | noncrystalline    | short-range cluster order | process-dependent                    |

No one allotrope represents all elemental-Boron properties.
