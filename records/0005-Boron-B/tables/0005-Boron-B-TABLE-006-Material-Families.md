# Boron Material Families

| Material        | Principal Relationship | Property Classes                                     |
| --------------- | ---------------------- | ---------------------------------------------------- |
| B₄C             | B–C ceramic            | hardness, neutron absorption, low density            |
| h-BN            | B–N layered solid      | electrical insulation, lubrication, thermal behavior |
| c-BN            | B–N cubic solid        | extreme hardness                                     |
| B₂O₃            | B–O oxide              | glass/network former                                 |
| borosilicate    | B–Si–O                 | low expansion, thermal shock resistance              |
| boranes         | B–H                    | multicentre/polyhedral chemistry                     |
| MgB₂            | B–Mg                   | superconductivity                                    |
| TiB₂            | B–Ti                   | refractory conductive ceramic                        |
| ZrB₂            | B–Zr                   | ultra-high-temperature ceramic                       |
| HfB₂            | B–Hf                   | ultra-high-temperature ceramic                       |
| B-doped Si      | doped host             | p-type semiconductor                                 |
| B-doped diamond | doped host             | acceptor state; superconductivity at suitable doping |
