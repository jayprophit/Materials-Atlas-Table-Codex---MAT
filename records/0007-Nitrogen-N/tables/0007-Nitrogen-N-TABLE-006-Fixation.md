# Nitrogen Fixation Pathways

| Pathway     | Input   | Output Family      | Driver                    |
| ----------- | ------- | ------------------ | ------------------------- |
| Haber-Bosch | N₂ + H₂ | NH₃                | catalyst + T + P          |
| biological  | N₂      | NH₃/NH₄⁺           | nitrogenase + ATP/e⁻      |
| lightning   | N₂ + O₂ | NOₓ                | electrical/thermal energy |
| plasma      | N₂      | excited/reactive N | electron energy           |
