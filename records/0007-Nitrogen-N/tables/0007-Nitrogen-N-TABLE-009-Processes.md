# Nitrogen Process Matrix

| Process             | State Change                          |
| ------------------- | ------------------------------------- |
| liquefaction        | N₂(g) → N₂(l)                         |
| Haber-Bosch         | N₂ → NH₃                              |
| biological fixation | N₂ → fixed N                          |
| nitrification       | NH₄⁺ → NO₂⁻ → NO₃⁻                    |
| denitrification     | NO₃⁻ → N₂                             |
| anammox             | NH₄⁺ + NO₂⁻ → N₂                      |
| plasma activation   | N₂ → N₂*/N₂⁺/N/N⁺                     |
| nitriding           | surface/material → nitride-rich state |
| high P/T            | N₂ → polymeric N                      |
