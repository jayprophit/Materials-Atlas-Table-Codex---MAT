# Hydrogen Charge States

| State | MAT ID           | Charge | Representative Description | Notes                                                            |
| ----- | ---------------- | -----: | -------------------------- | ---------------------------------------------------------------- |
| H⁻    | MAT:0001:ION:H-1 |     -1 | hydride anion              | one nucleus, two electrons                                       |
| H     | MAT:0001:ATOM:H  |      0 | neutral atomic Hydrogen    | isotope must still be identified where nuclear properties matter |
| H⁺    | MAT:0001:ION:H+1 |     +1 | positive Hydrogen ion      | ¹H⁺ is a proton; D⁺ and T⁺ contain different nuclei              |
| H₂    | MAT:0001:MOL:H2  |      0 | neutral molecule           | not an ion                                                       |
| H₂⁺   | MAT:0001:ION:H2+1 |     +1 | molecular hydrogen ion     | dedicated molecular-ion record required                          |
| H₃⁺   | MAT:0001:ION:H3+1 |     +1 | triatomic hydrogen ion     | important molecular ion; dedicated child required                |

Charge state alone does not define isotope or molecular identity.
