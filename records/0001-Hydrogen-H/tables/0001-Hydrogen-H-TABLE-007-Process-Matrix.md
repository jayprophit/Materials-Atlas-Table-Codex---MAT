# Hydrogen Process Matrix

| Process              | Input State         | Output State                  | Primary Driver                          | Class             |
| -------------------- | ------------------- | ----------------------------- | --------------------------------------- | ----------------- |
| Dissociation         | H₂                  | 2H                            | thermal / photonic / plasma / catalytic | physical-chemical |
| Ionisation           | H                   | H⁺ + e⁻                       | photon / electron / plasma energy       | electronic        |
| Recombination        | H + H               | H₂                            | collision/surface pathway               | chemical          |
| Liquefaction         | H₂(g)               | H₂(l)                         | cooling / pressure                      | cryogenic         |
| Solidification       | H₂(l)               | H₂(s)                         | cooling / pressure                      | phase             |
| Electrolysis         | H₂O-containing feed | H₂ + coproducts               | electricity                             | electrochemical   |
| Fuel-cell conversion | H₂ + oxidant        | products + electricity + heat | electrochemistry                        | energy conversion |
| Adsorption           | H₂/H                | surface-associated H          | host surface                            | materials         |
| Absorption           | H                   | host-contained H              | host chemical potential                 | materials         |
| Hydride formation    | H + host            | hydride                       | chemistry                               | materials         |
| Diffusion            | H at position A     | H at position B               | concentration / chemical potential      | transport         |
| D-T fusion           | ²H + ³H             | ⁴He + n                       | nuclear collision                       | nuclear           |
| Tritium decay        | ³H                  | ³He + β⁻ + antineutrino       | spontaneous nuclear decay               | nuclear           |

Chemical and nuclear processes remain separate.
