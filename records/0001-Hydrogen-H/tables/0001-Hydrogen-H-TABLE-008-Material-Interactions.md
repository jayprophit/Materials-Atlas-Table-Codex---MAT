# Hydrogen Material Interactions

| Host / Class             | Interaction                      | Mechanism Class         | Key Conditions                                |
| ------------------------ | -------------------------------- | ----------------------- | --------------------------------------------- |
| Magnesium systems        | hydride formation                | chemical storage        | T, P, phase, cycling                          |
| Palladium                | absorption / diffusion           | interstitial host       | T, P, H/Pd ratio                              |
| Nickel                   | catalysis / surface interaction  | catalytic               | surface, T, composition                       |
| Carbon / porous carbon   | adsorption                       | sorption                | T, P, pore structure                          |
| Boron-containing systems | complex hydride relationship     | chemical storage        | composition, T, P                             |
| Structural metals        | permeation / trapping            | transport               | microstructure, stress, T                     |
| Susceptible alloys       | hydrogen-assisted degradation    | mechanical relationship | H concentration, stress, strain rate, history |
| Semiconductor materials  | passivation / defect interaction | electronic/material     | process conditions                            |

No interaction in this table is automatically an intrinsic property of elemental Hydrogen.
