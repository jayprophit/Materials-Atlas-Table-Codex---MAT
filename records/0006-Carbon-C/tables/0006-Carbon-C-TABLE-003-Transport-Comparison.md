# Carbon Transport Architecture

| State       | Electrical                     | Thermal            | Critical State Variable |
| ----------- | ------------------------------ | ------------------ | ----------------------- |
| Diamond     | intrinsically highly resistive | very high possible | purity/isotopes         |
| Graphite    | conducting                     | highly anisotropic | direction               |
| Graphene    | high-mobility possible         | very high in-plane | substrate/defects       |
| CNT         | metallic or semiconducting     | axial transport    | chirality               |
| Amorphous C | process-dependent              | process-dependent  | sp²/sp³ fraction        |
