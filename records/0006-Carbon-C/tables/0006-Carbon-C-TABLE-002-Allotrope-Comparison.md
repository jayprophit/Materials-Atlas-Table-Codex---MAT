# Carbon State Comparison

| State       | Dimensionality | Bonding/Topology          | Electronic Character |
| ----------- | -------------- | ------------------------- | -------------------- |
| Diamond     | 3D             | sp³-like tetrahedral      | wide-gap             |
| Graphite    | layered 3D     | sp²-like sheets           | semimetallic         |
| Graphene    | 2D             | honeycomb sheet           | Dirac-like           |
| CNT         | 1D             | rolled graphitic topology | chirality-dependent  |
| C₆₀         | 0D             | closed cage               | molecular            |
| Amorphous C | disordered 3D  | mixed local bonding       | process-dependent    |
