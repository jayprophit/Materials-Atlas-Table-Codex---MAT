# Beryllium Process and Safety Matrix

| Process             | Relevant State        | Major Concern                             |
| ------------------- | --------------------- | ----------------------------------------- |
| machining           | solid Be              | airborne particulate                      |
| grinding            | solid Be              | fine dust                                 |
| powder metallurgy   | powder                | inhalation/exposure                       |
| sintering           | powder/compact        | process emissions                         |
| oxidation           | hot Be                | BeO formation                             |
| X-ray window use    | thin foil             | photon attenuation + structural integrity |
| neutron environment | ⁹Be-rich material     | nuclear reactions / irradiation           |
| recycling           | contaminated material | exposure control                          |
| BeO processing      | ceramic powder        | Beryllium-containing dust                 |

Safety must be linked directly to process and material form.
