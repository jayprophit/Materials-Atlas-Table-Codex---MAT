# Historical models and alternative periodic arrangements

These references are a research collection. Element identity, atomic number and source-backed measurements come from the canonical MAT catalogue. A visually suggestive correspondence does not establish a scientific mechanism.

| Reference | Classification | Treatment |
|---|---|---|
| Walter Russell wavelength spiral | Historical/alternative cosmology | Keep octave, charging and zero-motion claims outside scientific properties. Existing MAT mappings conflict with the supplied chart and remain unverified. |
| Kamal Akhtar angular table | Alternative educational layout | Preserve attribution. Older temporary element names require correction; angle is a display coordinate, not a measured atomic property. |
| Makeev dual spiral | Speculative extended arrangement | Labels beyond Z=118 are not discovered elements. They receive no MAT chemical-element IDs. |
| Pyramidal subshell layout | Educational arrangement | Shell capacity illustration; diagram is not a scale drawing of orbitals or a source for ground-state exceptions. |
| Harrington polar projection | Alternative theoretical model | Counter-proton and 270 AMU claims are unverified; no scientific overlay generated. |
| Rafael Poza toroidal arrangement | Alternative geometric model | Do not present a toroidal graphic as measured elemental magnetosphere data. |
| Dendritic periodic tree | Historical visualization | Useful navigation idea; not a biological lineage. |
| Sheehan abundance cartogram | Historical data visualization | Requires a specified abundance dataset, units and conditions. The reference bears a rights notice and is not bundled in distributed editions. |
| Helical / twin-cone / concentric layouts | Alternative educational layouts | Useful spatial navigation, but retain one authoritative 118-element identity catalogue. |

The supplied archives and images are retained locally under the ignored .mat-local/intake directory with SHA-256 inventory. They are not bundled as verified scientific evidence. The richer archive mixes baseline facts with speculative assertions and zeros used as unknown sentinels; its numeric data is deliberately excluded from the canonical catalogue.

## Adopted interaction ideas

The Studio adapts the supplied book's manuscript and page workspace, parchment/paper/night themes, adjustable reading size, separate data and figure inspection, collapsed chapter tree, element selection, bookmarks and explicit evidence tiers. Generated publication shards, durable local drafts, conflict detection, accessible controls and draft exports are wired to the current repository.

## Release gates

Source identity and image rights must be established before historical reference artwork is distributed. No renderer may map proposed elements to chemical-element IDs beyond Z=118. Any future alternate geometry should take element IDs from the canonical catalogue and store layout coordinates separately from scientific properties.


## Original Russell source now available

The complete 1926 source (SRC-000324) and its original diagrams are preserved in the [Russell primary-source collection](Russell-1926-Primary-Source.md). The older nine-octave JSON remains explicitly unverified; the source has ten octaves. No legacy values were deleted or promoted to measured atomic frequencies.
