# MAT Global References

## Purpose

This file contains sources used across multiple MAT documents.

Record-specific scientific sources should normally remain linked to their corresponding numbered record.

Use the [generated source directory](../05-index/Source-Navigation.md) for registered source entries, internal usage backlinks, external URLs/DOIs and retained snapshots. The [canonical registry](../../data/registries/sources.yaml) owns bibliographic metadata; the directory is a derived navigation aid. Unresolved references remain visible for review. Source-specific citation export and missing author/year/rights metadata remain [tracked documentation gaps](../05-index/Documentation-Gap-Analysis-2026-10-03.md).

