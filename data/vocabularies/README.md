# Vocabularies

This directory holds the controlled vocabularies and relationship dictionaries used by MAT.

[glossary.json](glossary.json) owns the migrated editorial terminology. The prose,
book hover and publication projections are generated from it. Read the
[terminology guide](../../docs/02-data/14-Canonical-Terminology.md) for origin
preservation, review limits and update commands. Preferred/alternate labels do
not establish a complete thesaurus or scientific relationship graph.
